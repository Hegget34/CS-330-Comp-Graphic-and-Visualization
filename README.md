# CS-330 3D Scene Project

## Project Overview
For this project, I created a 3D scene using OpenGL with a wine glass, champagne bottle, black box, and orange on a wooden table, including camera controls for exploring the scene.

## How do I approach designing software?

### New Design Skills
I learned to break down complex objects into basic shapes, like creating a wine glass from different cylinders. Getting transparent glass to look right by implementing blending in OpenGL was challenging but rewarding.

### Design Process
I started by analyzing my reference image and identifying how to build each object with primitive shapes. I focused on getting the basic structure right before refining details, constantly adjusting positions and scales until everything looked proportional.

### Future Application
Breaking complex problems into smaller parts will help me in future programming work. The modular approach and organized functions I created made my code cleaner and easier to modify, which is a practice I'll continue using.

## How do I approach developing programs?

### New Development Strategies
Separating setup code from rendering code helped organize my work. I learned to handle transparency by drawing transparent objects last and creating helper functions for common tasks like setting transformations and applying textures.

### Role of Iteration
I built my scene step by step, starting with basic shapes and gradually adding details. The champagne bottle began as a simple cylinder before I added shoulders, neck, and cap. Each iteration brought the scene closer to my vision.

### Evolution of Approach
My approach evolved from just getting objects on screen to thinking about code organization and creating specialized functions. I improved at debugging and learned to check transformation matrices and texture coordinates when something looked wrong.

## How can computer science help me in reaching my goals?

### Future Educational Pathway
This project sparked my interest in 3D math, game development, and user interface design. I'm curious to take more courses in these areas to build on what I've learned.

### Future Professional Pathway
Whether or not I pursue graphics programming specifically, the problem-solving skills I developed will help in any programming role. Breaking down complex problems, writing organized code, and thinking about user interaction are valuable skills for any developer.
